# Skill: Gameplay, Interaction & Rendering

Use for camera, tools, target zones, glass/water rendering, HUD, input, environments and accessibility.

## Interaction
Desktop: orbit + zoom, explicit precision aim, hold-to-use, release-to-stop, quick tool/diameter switching.
Touch: preserve one-finger interaction and two-finger navigation or provide an explicit mode switch. Never rely on hover-only information.

## Precision drilling
Model explicit states: idle -> aim -> approach -> contact -> drilling -> breakthrough -> retract.

Quality inputs: target-point error, angle to surface normal, relative glass motion, pointer/tool motion and tool characteristics.

## Rendering
Visual identity: premium readable glass, believable water, selective refraction, caustics-like light where affordable, restrained HUD, varied box environments.

Avoid unlimited stacked alpha surfaces, effects that obscure targets, and particles as gameplay state. Add quality tiers before expensive effects.
